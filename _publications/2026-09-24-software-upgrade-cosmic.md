This paper investigates the use of COSMIC functional size measurement for a portability-driven software upgrade, using the Java 8-to-17 upgrade of SimSE as a case study.

The study examines how functional sizing can provide quantitative information to support software upgrade planning, benchmarking, and future effort estimation.
