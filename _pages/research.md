## Research Interests

My research interests lie at the intersection of software measurement, software estimation, and software engineering education.

- Software Measurement
- Software Estimation
- COSMIC Functional Size Measurement
- Early Software Sizing
- Software Size–Effort Relationships
- Software Engineering Education
- Educational Games for Software Engineering

## Current Research

### Early Software Sizing

My research investigates techniques for estimating software functional size at early stages of the software development lifecycle, when requirements information is still incomplete.

### Software Size and Effort Estimation

I am interested in the relationship between software functional size and development effort, including the construction and evaluation of software estimation models.

### Software Engineering Education

My research also explores the use of educational games to support the teaching and learning of software estimation and measurement concepts.

### COSMIC Functional Size Measurement

COSMIC functional size measurement is a central component of my research and professional experience. My work connects the application of COSMIC in industry with empirical research on software sizing and estimation.


## Selected Research Projects

### Comparative Study of Early Software Sizing Techniques

A comparative study of fifteen techniques for estimating software functional size from early and incomplete software requirements. The research examines the applicability and accuracy of different early sizing approaches using a common case study.

**Research focus:** Early software sizing · Functional size measurement · Software estimation

---

### Software Estimation Educational Games

Design and development of a suite of six educational games for teaching software estimation concepts. The games are based on SimSE and cover different estimation activities and decision-making scenarios.

The project also investigates how these games can be used in graduate-level and professional software engineering education.

**Research focus:** Software estimation · Software engineering education · Educational games · SimSE

---

### Functional Sizing of a Software Application Generator

A case study applying the COSMIC functional size measurement method to the SimSE educational game generator. The study investigates the functional size of a software application generator and its generated software products.

**Research focus:** COSMIC · Functional size measurement · Software generators

---

### COSMIC Measurement of a Software Version Upgrade

A case study of a software version upgrade measured using the COSMIC ISO standard. The research examines the functional changes involved in the upgrade and explores the management lessons that can be derived from functional size measurement.

**Research focus:** COSMIC · Software maintenance · Software measurement · Project management
